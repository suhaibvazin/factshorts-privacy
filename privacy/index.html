Privacy Policy

Last updated: 9 November 2026

This policy describes how the "Fact-ory" application ("the app") handles information. The app is a personal tool operated by the owner of the Fact-ory YouTube channel to upload and schedule that channel's own videos.

Who uses the app

Only the channel owner. The app is not offered to the public and no other person signs in to it.

What the app accesses

The app uses the YouTube Data API with the youtube.upload permission, granted by the channel owner, solely to upload videos, set their titles, descriptions, tags, thumbnails and publish times on the owner's own channel. It does not read, collect or store data about viewers, subscribers or any other YouTube users.

How data is stored

The authorization token is stored as an encrypted secret in the owner's private GitHub repository and is used only to perform the uploads described above. No personal data is sold, shared with third parties, or used for advertising.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google account security page: myaccount.google.com/permissions.

Contact

Questions about this policy can be sent to the channel owner via the Fact-ory YouTube channel.
